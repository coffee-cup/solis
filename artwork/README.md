# Solis icon

`Solis.icon` is the app's primary icon. Open it in Icon Composer to edit the sky gradient and glass horizon. The dark appearance uses a slate-blue to indigo sky.

The horizon vector is stored inside the icon document. Icon Composer supplies its highlights, translucency, and shadow. The original SVG and PNG asset catalogue remain available as source artwork.
